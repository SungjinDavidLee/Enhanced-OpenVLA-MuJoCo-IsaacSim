# Isaac Sim에서의 VLA 로봇 정책 평가 — MuJoCo에서 학습한 모델을 다른 시뮬레이터로 옮겼을 때

English: [README_en.md](README_en.md)

로봇 팔이 「검은 그릇을 집어 접시 위에 놓는」 과제를 하도록 MuJoCo 시뮬레이터에서 학습된 인공지능 모델(OpenVLA 계열)을, 추가 학습 없이 Isaac Sim 시뮬레이터로 옮겨 시험한 기록이다. 성공률이 얼마나, 왜 떨어지는지를 밝히고, Isaac Sim 화면으로 다시 학습시켜 성공률을 되찾는 것이 목표다. 결과는 보고서 단위로 차례로 공개하며, 이 문서는 보고서가 나올 때마다 갱신한다.

## 지금까지의 결과

| 보고서 | 핵심 |
| --- | --- |
| 1-1 | 평가 코드의 결함을 고치자, 같은 조건(실행 설정 · 물체 위치 · 500판)에서 그릇을 실제로 집은 성공률이 12.6 %에서 22.8 %로 올랐다. 남은 실패의 대부분은 그릇을 물고도 들지 못하거나 그릇 바깥에서 손을 닫는 경우였고, Isaac Sim에서는 그릇 한쪽을 집으면 그릇이 크게 기운다(38–54°, MuJoCo 2–15°) |
