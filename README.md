# Isaac Sim 에서의 LIBERO-Spatial VLA 제로샷 평가 — 어댑터 · 하네스 수정과 실패 원인 분석 (v2)

MuJoCo(LIBERO)에서 학습된 VLA 정책(OpenVLA, OpenVLA-OFT)을 Isaac Sim 6.0.1 의 LIBERO-Spatial 재현 장면에서 평가하는 파이프라인을 점검하고 고친 기록이다. 평가 하네스와 어댑터(정책 액션 → 로봇 동작)의 결함을 찾아 고쳤고, 어댑터의 실행 배율을 MuJoCo 와 개루프로 맞춘 뒤 남은 실패의 원인을 물리 엔진의 접촉 차이로 좁혔다.

작성 2026-09-28 (v1) · 갱신 2026-10-01 (v2). v1 은 `README_v1_2026-09-28.md` 로 보존했다. v1 이후 바뀐 결론은 [부록 A](#부록-a-v1--v2-정정-목록)에 모았다.

**요약.** (1) 하네스 결함만 고쳐도 같은 정책 · 같은 배치에서 실제 성공률이 12.6 % → 22.8 % 가 됐다. (2) 어댑터의 실행 배율을 MuJoCo 와 맞추자 청크를 실행하는 OFT 는 11.0 % → 46.5 % 가 됐고(배치도 함께 바뀜), 「허공에서 닫는」 실패가 94 판 → 0 판으로 사라졌다. 매 스텝 다시 보는 OpenVLA 는 반대로 빠른 실행에서 더 높았다. (3) 남은 실패의 97 % 는 「테두리를 물었는데 그릇이 안 들림」 이고, 정책 없는 파지 시험으로 **Isaac 에서 한쪽 테두리를 쥐면 그릇이 쥔 곳을 축으로 크게 기우는** 접촉 차이가 원인임을 확인했다.

## 1. 배경

LIBERO-Spatial 은 10 개 태스크의 픽앤플레이스 벤치마크다. 모든 태스크가 「특정 위치의 검은 그릇을 접시 위에 놓기」 이고, 그릇의 위치(쿠키 상자 옆, 라메킨 위, 서랍 안 등)가 태스크를 가른다. 공개 VLA 체크포인트는 모두 이 벤치마크의 MuJoCo 사람 시연 500 개로 미세조정되어 있다.

이 작업은 그 정책들을 Isaac Sim 으로 옮겼을 때 성공률이 얼마나, 왜 떨어지는지 재고, Isaac 화면으로 다시 학습시켜 회복시키는 연구의 평가 · 데이터 파트다. 정책은 HTTP 서버로 띄우고, 브리지(`run_openvla_isaac_bridge.py`)가 관측을 보내고 받은 액션을 어댑터 · Lula IK · PhysX 로 실행한다 (5 절).

- **하네스**: 정책 출력을 로봇 동작으로 바꾸고, 판을 진행 · 종료 · 판정하는 평가 코드 전체.
- **어댑터**: 그중 「LIBERO 액션 → Isaac 손 목표 → 관절 동작」 으로 바꾸는 부분 (6 절).
- **제로샷**: Isaac 데이터로 추가 학습 없이 그대로 평가하는 것.

## 2. 무엇이 문제였고 어떻게 고쳤나

### 2.1 평가 하네스 · 어댑터

| 문제 | 증상 · 근거 | 해결 | 효과 |
|---|---|---|---|
| 조기 종료 관문 (닫기 6 회 제한, IK 연속 실패 중단, 온라인 닫기 재시도 3 회) | 500 판 중 **395 판**이 220 스텝 전에 끊김 | 관문 해제 (`1000 / observe / 1000`), 실패는 220 스텝 소진으로만 | 조기 종료 395 → **0** |
| 집게 즉시 닫힘 | 닫기 명령에 팔을 멈추고 0.35 초에 닫음. MuJoCo 는 약 0.7 초 동안 팔이 계속 내려감 | 위치 목표만 주고 PD 로 자연스럽게 닫힘 (`--close-approach-settle-steps 0 --gripper-settle-steps 1`) | 닫힘 타이밍을 MuJoCo 와 맞춤 |
| 방향 제약을 푼 IK 대체 | 평가에서 손이 임의 방향으로 틀어져 한 배치 0/69 | 평가에서 끔 (`--no-ik-position-fallback`), IK 실패 시 현재 자세 유지 | |
| 실행 배율 미검증 | v1 은 성공률이 높은 S=10 · gain 1.0 을 채택. 같은 명령에 MuJoCo 와 다른 거리를 움직임 | **사람 시연 명령 개루프 재생으로 검증**, MuJoCo 와 일치하는 S=3 · gain 0.65 를 공통 조건으로 (6 절) | 접근 구간 이동비 1.26 → **1.02** |
| 렌더 비용 | 물리 서브스텝마다 렌더 | 마지막 서브스텝만 렌더 | 판당 3–5 분 → 1–2 분 |
| 무응답 판 | 7 시간 멈춘 판 발생 | 감시자: 로그 5 분 정지 시 끊고 재시도 (`watchdog_v2.sh`, v1 은 15 분) | |

### 2.2 성공 판정

| 문제 | 해결 |
|---|---|
| 접시 반경 판정이 **쥐지 않고 밀어 올린 21 판**을 성공으로 셈 (16.8 % → 실제 12.6 %) | **S9** 판정 (발자국 · 높이 · 정지 · 30 mm 위에서 하강) + 모든 성공 판의 **파지 감사** (손가락 폭 · `gripper_holding_ok`) |
| 기운 그릇(48.4°)이 배치 판정을 통과한 사례 | S9 의 높이 · 정지 조건 |
| 도달 단계 `stage_level` 의 S4 이후가 부정확 (성공 114 판 중 92 판이 S3 으로 기록) | 실패 분석은 **물리 신호 5 부류**로 (3.3 절) |

### 2.3 재생 · 학습 데이터

| 문제 | 증상 · 근거 | 해결 |
|---|---|---|
| 손 방향 쿼터니언 순서 | LIBERO `eef_quat` 은 xyzw, 브리지 기본 wxyz → 목표 방향 최대 50° 오차, 먼 태스크 IK 실패 판당 1,522 · 1,594 회 | `--libero-eef-quat-order xyzw` → IK 실패 0, 추종 오차 0.5–0.6° (그림 4, 5) |
| 재생 스텝 100 | 긴 궤적이 놓기 전에 잘림 (118 판) | 220 |
| 서브스텝 IK 예외 | 브리지가 통째로 종료 (170 판) | 그 서브스텝만 현재 자세 유지 |
| task 5 높이 | 라메킨 높이를 낙하 전 공중에서 재서 그릇이 22 cm 위에서 떨어짐 | 받침 정렬을 끈 전용 설정 |
| 재생 z +15 mm | 테두리 위 허공에서 닫힘 | 0, 수집 기본 −6 mm (task 0 실패 14 판 중 6 판 회복). 모자란 궤적은 −10 mm 로 재시도해 9 개 추가 |
| 채택 기준 | 파지(S4)만 성립해도 채택 | 과제 성공(S9) 만 |
| **화면 시간 정렬 (v2 에서 발견)** | 재생 모드는 스텝 k 동안 로봇을 시연 k 번째 자세로 옮기고 화면은 스텝 시작에 찍어, 화면 k 가 k−1 번째 자세 | 학습셋에서 **스텝 k 에 화면 k+1** 사용 (8 절, 그림 19). 정책 평가에는 영향 없음 |

### 3.2 단계(S0–S9)로 본 변화

옛 하네스는 500 판 중 395 판을 중간에 끊었기 때문에, 옛 하네스의 단계 분포는 「정책이 어디서 멈췄나」 가 아니라 「관문이 어디서 끊었나」 를 보여 줘 직접 비교할 수 없다. 고친 하네스에서 보이는 변화는 이렇다.

| 단계 | 옛 하네스 | 고친 하네스 (OpenVLA 빠른 · s00) |
|---|---|---|
| 끝까지 진행 | 105 / 500 판 | **500 / 500 판** |
| S9 성공 중 쥐지 않은 성공 | 21 / 84 | **0 / 114** |
| 실패가 멈춘 단계 | 비교 불가 (관문 종료) | S0 6 · **S3 222 · S4 115** · S5 25 · S6 16 · S7 2 (실패 386 판) |

실패 386 판 중 337 판(87 %)이 S3–S4 (그릇 위로 손을 맞추고 테두리를 무는 구간)에서 멈췄다. 다만 성공 판의 다수도 S3 으로 기록될 만큼 S4 이후 기록이 부정확해, 아래 물리 신호 분류로 다시 봤다.

### 5.4 수식

**(1) LIBERO 액션 규약.** 액션 $a = (a_x, a_y, a_z, a_{rx}, a_{ry}, a_{rz}, a_g) \in [-1, 1]^7$.

$$\Delta p = 0.05\,[a_x, a_y, a_z]^\top \ \text{m}, \qquad \Delta\theta = 0.5\,[a_{rx}, a_{ry}, a_{rz}]^\top \ \text{rad}, \qquad a_g = -1\ \text{(열림)},\ +1\ \text{(닫힘)}$$

**(2) 어댑터 손 목표.** 현재 손끝 $p_t, R_t$, 실행 배율 $g$:

$$p^\ast = p_t + g\,\Delta p, \qquad R^\ast = \exp\!\big([g\,\Delta\theta]_\times\big)\,R_t$$

**(3) 스텝 시간.** 물리 60 Hz, 액션당 서브스텝 $S$ 이면 $\Delta t = S / 60$ s. 보정 $S=3$ 은 0.05 s (MuJoCo 20 Hz 와 같음), 빠른 $S=10$ 은 0.167 s.

**(4) IK 와 되돌림.** $q^\ast = \mathrm{IK}(p^\ast, R^\ast)$. 실패하면 $g \leftarrow \beta g$, $\beta \in \{1.0, 0.5\}$ 로 다시 풀고, 모두 실패하면 $q^\ast = q_t$ (현재 자세 유지).

**(5) 카메라 화각.** 정사각 픽셀 핀홀은 세로 화각이 가로 화각과 해상도로 정해진다.

$$\mathrm{FOV}_v = 2\arctan\!\Big(\tan\tfrac{\mathrm{FOV}_h}{2}\cdot\tfrac{H}{W}\Big) = 2\arctan(\tan 43.5^\circ \cdot 480/640) = 70.9^\circ$$

정사각으로 자른 뒤 면적 $a$ 를 가운데에서 자르면 $\mathrm{FOV}(a) = 2\arctan\!\big(\tan 35.45^\circ\cdot\sqrt{a}\big)$. $a = 0.35$ → 45.7° (LIBERO 학습 화면 45°), $a = 0.9$ → 68.1°.

**(6) OFT 상태 프레임 변환.** Isaac `right_gripper` 자세 $(p_{rg}, R_{rg})$ → robosuite `robot0_eef`:

$$R_{eef} = R_{rg} R_{off}, \qquad p_{eef} = p_{rg} + R_{rg}\,p_{local}, \qquad R_{off} = \mathrm{Rot}(180^\circ),\ \lVert p_{local}\rVert = 3.7\ \text{mm}$$

**(7) 실행 배율 검증 (개루프).** 같은 시연 명령을 재생한 Isaac 손끝 $p^I_k$ 와 MuJoCo 기록 $p^M_k$:

$$r_W = \frac{\lVert p^I_W - p^I_0\rVert}{\lVert p^M_W - p^M_0\rVert}, \quad r^{(c)}_{24} = \frac{p^I_{24,c} - p^I_{0,c}}{p^M_{24,c} - p^M_{0,c}}, \quad e_{pos} = \lVert p^I_{k_c} - p^M_{k_c}\rVert, \quad e_{rot} = \arccos\frac{\mathrm{tr}(R^{I\top}_{k_c} R^M_{k_c}) - 1}{2}$$

$W \in \{8, 24, k_c\}$, $k_c$ = 첫 닫기 명령. 합격: $|r_{k_c} - 1| \le 0.05$, $|r_{24} - 1| \le 0.05$, $|r^{(c)}_{24} - 1| \le 0.10$, $e_{pos} \le 30$ mm, $e_{rot} \le 10^\circ$.

**(8) S9 성공.** 그릇 바닥 중심 $b$, 접시 윗면 높이 $z_p$:

$$b_{xy} \in \text{접시 유효 영역},\quad |b_z - z_p| \le \epsilon_z,\quad \lVert v\rVert \le v_{th},\ \lVert\omega\rVert \le \omega_{th},\quad \max_{\tau < t} b_z(\tau) \ge z_p + 30\ \text{mm}$$

**(9) 성공률 신뢰구간.** Wilson 95 %: $\dfrac{\hat p + \frac{z^2}{2n} \pm z\sqrt{\frac{\hat p(1-\hat p)}{n} + \frac{z^2}{4n^2}}}{1 + z^2/n}$, $z = 1.96$.

**(10) 결과 5 부류.** 손가락 평균 폭 $w_t$, 그릇 바닥 상승 $\ell = \max_t b_z - b_{z,0}$, 끝 거리 $d = \lVert b_{xy,T} - p_{xy}\rVert$:

$$\text{A: S9}; \quad \ell < 40\,\text{mm} \Rightarrow \begin{cases}\text{B} & \exists\, 3\ \text{연속}\ 2.5 < w_t < 12\ \text{mm}\\ \text{C} & \text{otherwise}\end{cases}; \quad \ell \ge 40\,\text{mm} \Rightarrow \begin{cases}\text{E} & d < 100\ \text{mm}\\ \text{D} & d \ge 100\ \text{mm}\end{cases}$$

**(11) 학습셋 시간 정렬 판정.** 지연별 상관 $c_L$ 의 봉우리를 포물선으로 칸 사이까지 추정한다.

$$L^\ast = L_i + \frac{1}{2}\,\frac{c_{i-1} - c_{i+1}}{c_{i-1} - 2c_i + c_{i+1}}$$

원본 LIBERO 의 $L^\ast$ 와 0.5 스텝 안이면 정렬된 것으로 본다 (그림 19).
