# 보고서 1-2. 실행 설정과 물체 위치에 따른 차이 (준비 중)

보고서 1-1의 결과(22.8 %)는 원래 학습 환경과 다르게 움직이는 실행 설정과, 물체 위치 1가지에서 잰 값이다. 이 보고서는 같은 판 수(500판)로 「MuJoCo와 같은 속도」와 「물체 위치 50가지」의 경우를 재서, 실행 설정과 물체 위치가 각각 성공률에 주는 영향을 나눈다.

# Report 1-2. Effects of the execution setting and object placement (in preparation)

The 22.8 % in Report 1-1 was measured with an execution setting that moves differently from the training environment and with a single object placement. This report measures the MuJoCo-matched speed and 50 object placements with the same episode count (500) to separate the effect of each.
